# Benefit Paydays (independent, unofficial)

Static site: next Social Security / SSI / VA / SNAP payment date lookup, month pages Nov 2026 – Dec 2027, .ics feeds, 2027 COLA calculator.
Not affiliated with SSA, VA, USDA or any government agency.

Build: `cd gen && python3 build.py` → writes `docs/` (served by GitHub Pages). The build asserts computed SSA/SSI dates equal SSA Publication 05-10031 (2026, 2027).
